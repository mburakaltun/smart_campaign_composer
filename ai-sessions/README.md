# AI session export'ları

Bu klasöre case boyunca Claude ile yapılan **tüm** çalışma session'larının export'ları eklenir:

* Claude Code: `/export` ile üretilen dosya
* claude.ai: paylaşım linki (bu klasördeki `links.md` içine)

Göndermeden önce API key'leri, e-posta/telefon gibi kişisel bilgileri ve `.env` içeriğini temizleyin.

| Dosya | İçerik |
|---|---|
| `session-1.md` | Case'in tamamının yapıldığı claude.ai sohbetinin metin dökümü (kişisel bilgiler çıkarıldı; ayrıntı dosyanın başında) |
